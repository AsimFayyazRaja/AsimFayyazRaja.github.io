Instantly · B2B search platform

Real-time PostgreSQL → Elasticsearch CDC at 600M-record scale

Built and operate change-data-capture from PostgreSQL into Elasticsearch with Kafka, Debezium and Flink SQL, carrying inserts, updates and deletes with low latency. Added version-aware writes keyed on PostgreSQL log sequence numbers (LSNs) so stale stream or backfill events can never overwrite newer data. During live cluster incidents I ran replay and recovery and confirmed that every affected event was recovered.

~600Mlead records kept in sync

Instantly · Search performance

Distributed geospatial search: 19.6s → 2.3s

Diagnosed slow location-filtered searches down to oversized polygon query payloads. Shrank the payloads about 16× with no change to the result set, which brought a representative search from 19.6 seconds to 2.3.
